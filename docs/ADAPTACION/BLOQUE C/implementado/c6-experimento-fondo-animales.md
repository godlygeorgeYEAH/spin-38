# C6 — Experimento: eliminar fondo de animales y aro interior

El cliente quiere ver cómo se ve la rueda si se eliminan los fondos de los segmentos del anillo interior y el aro decorativo que los rodea.

## Qué probar

- **Fondo de segmentos del anillo interior:** actualmente cada segmento tiene un gradiente de color sólido. Eliminar o hacer transparente ese fondo para que solo se vean las imágenes de los animales.
- **Aro del anillo interior:** el borde/aro que separa el anillo interior del exterior. Evaluarlo eliminado o en opacidad reducida.

## Criterio de aceptación

Este es un experimento visual, no una feature. El entregable es una captura/demo en vivo para que el cliente decida si le gusta. No hay criterio de completitud técnico hasta que el cliente apruebe la dirección.
